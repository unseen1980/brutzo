# Phase 1 Tone Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish Brutzo Phase 1 with a safe amp/cab/FX monitor, honest latency UI, and locally persisted processed-output WAV recorder.

**Architecture:** Extend the allocation-free Rust/WASM core for amp, cabinet voicing, gate, and compression; wrap it in a native Web Audio delay/ambience/master chain; capture final PCM through a recorder worklet and persist WAV takes in IndexedDB. Both microphone and WAV sources continue to enter through the existing `AudioGraph` selected-output boundary.

**Tech Stack:** React 19, TypeScript 5.9, Web Audio API, AudioWorklet, Rust stable targeting `wasm32-unknown-unknown`, IndexedDB, Vitest, GitHub Pages.

---

## File structure

- `app/dsp/tone-core/src/lib.rs`: allocation-free tone, cabinet, gate, and dynamics DSP plus WASM ABI.
- `app/dsp/tone-core/tests/tone.rs`: deterministic DSP behavior and preset-separation tests.
- `app/src/audio/tone.ts`: tone parameters, presets, worklet lifecycle, and master routing.
- `app/src/audio/fx.ts`: normalized FX state and native Web Audio delay/ambience graph.
- `app/src/audio/recorder.ts`: recorder worklet control, WAV encoding, and take construction.
- `app/src/audio/latency.ts`: honest latency labels, grade, and Bluetooth/wired guidance.
- `app/src/audio/storage.ts`: versioned IndexedDB calibration, latency, and take persistence.
- `app/public/audio/tone-processor.js`: WASM message ABI and final-output PCM recorder processor.
- `app/src/screens/Tone.tsx`: Phase 1 orchestration and focused cards.
- `app/src/screens/Home.tsx`: shipped Phase 1 status.
- `app/src/ui/global.css`: responsive tone, toggle, recorder, and latency layouts using existing tokens.
- `app/scripts/verify-build.mjs`: worklet/WASM deployment verification.
- matching `*.test.ts` files: pure behavior and regression coverage.
